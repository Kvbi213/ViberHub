## 1. DZIENNIK ZMIAN
- `[+]` **Persistent Navigation Layout:**
  - Utworzono layout `apps/web/app/(dashboard)/layout.tsx` z komponentem `Shell`.
  - Wyeliminowano anomalię znikania paska bocznego przy klikaniu w "Dashboard".
  - Wyeliminowano wielokrotne podświetlanie "Room Collab" i "Code & Git Diffs" dzięki nasłuchiwaniu zmian w `window.location.hash`.
- `[+]` **Firebase Authentication & User Stats:**
  - Dodano `apps/web/lib/auth-service.ts`: rejestracja, logowanie email/hasło, Google Sign-in oraz bezhasłowy "Tryb Gościa".
  - Wbudowano silnik odpornościowy na `auth/configuration-not-found`: automatyczna bezpośrednia sesja lokalna z natychmiastowym zapisem profilu w Cloud Firestore (`users/{uid}`), eliminująca zależność od płatnej konsoli GCP.
  - Zaimplementowano stoper czasu rzeczywistego (`activeCoopSessionSeconds`), który zlicza aktywny czas programowania w parze i automatycznie utrwala go w Cloud Firestore (`users/{uid}/stats`).
  - Utworzono `AuthModal.tsx` i `UserProfileModal.tsx` w stylistyce Apple Milky Glass z podglądem rang ("Co-op Novice" -> "Pair Pilot Pro" -> "Architect Elite"), liczby sesji i wyemitowanych zdarzeń.
- `[+]` **Rozbudowa Backend API (Vercel Serverless Microserver 24/7):**
  - `/api/v1/health` — bezproblemowy healthcheck microservera.
  - `/api/v1/users/stats` — pobieranie i rejestracja statystyk kooperacji.
  - `/api/v1/rooms/stats` — zestawienie aktywności pokoi i klastra obserwowalności.
  - Przekierowanie ruchu telemetrycznego do otwartego adresu produkcyjnego `https://viber-hub.vercel.app` bez blokad SSO.
  - Pełne nagłówki CORS (`*`) i obsługa preflight `OPTIONS 200 OK`.
- `[+]` **Automatyzacja Wdrożeniowa & Standalone CLI Runner:**
  - Zaimplementowano kompletny interfejs wiersza poleceń Bridge (`apps/bridge/src/cli.ts` + `apps/bridge/bin/cli.js`) z poleceniami: `pair <KOD>`, `start`, `status`, `help`.
  - Powiązano binaria `vibehub` oraz `vibehub-bridge` globalnie w systemie Windows (`npm link`), eliminując błąd `npm 404 Not Found` dla nieopublikowanego pakietu npm.
  - Zaimplementowano automatyczny zapis poświadczeń stacji do `~/.vibehub/bridge.json`.
  - Utworzono `scripts/build-firebase.ps1` wykonujący czysty eksport do `apps/web/out` z zachowaniem serwerowych tras API dla Vercela.
